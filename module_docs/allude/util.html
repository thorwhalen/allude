allude.util.get_edges(graph_spec, postprocess_edges=<function edge_to_node_ids>)[source]

Get a list of edges for a given graph (or list of lists thereof). If postprocess_edges is None the function will return pydot.Edge objects from which you can extract any information you want. By default though, it is set to extract the node pairs for the edges, and you can replace with any function that takes pydot.Edge as an input.

>>> digraph_dot_source = '''
... digraph {
...     rain -> traffic
...     rain -> wet
...     traffic -> moody
...     wet -> moody
... }
... '''
>>> assert (
...     get_edges(digraph_dot_source)
...     == get_edges(Source(digraph_dot_source))
...     == [('rain', 'traffic'), ('rain', 'wet'), ('traffic', 'moody'), ('wet', 'moody')]
... )
>>>
>>> graph_dot_source = '''
... graph {
...     rain -- traffic
...     rain -- wet
...     traffic -- moody
...     wet -- moody
... }
... '''
>>>
>>> assert (
...     get_edges(graph_dot_source)
...     == get_edges(Source(graph_dot_source))
...     == [('rain', 'traffic'), ('rain', 'wet'), ('traffic', 'moody'), ('wet', 'moody')]
... )
