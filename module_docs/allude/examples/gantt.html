allude.examples.gantt

Gantt chart example.

allude.examples.gantt.mermaid_gantt(annots: Iterable[dict[str, str | int | float]], *, title: str | None = None, date_format: str = 's', axis_format: str | None = None, group: Callable | None = None, task: str = 'task', bt: str = 'bt', tt: str = 'tt') → str[source]

Creates a Mermaid Gantt diagram string from the given annotations.

Parameters:

  • annots – Iterable of annotations (dicts with “task”, “bt”, and “tt” keys).

  • title – Optional title for the Gantt diagram.

  • date_format – Date format for the Gantt diagram. Default is ‘s’ (seconds). See https://mermaid.js.org/syntax/gantt.html#input-date-format for more info.

  • axis_format – Axis format for the Gantt diagram. Default is None (no axis). See https://mermaid.js.org/syntax/gantt.html#output-date-format-on-the-axis for more info

Returns:

A string in Mermaid Gantt diagram syntax.

>>> annots = [
...     {"task": "snap", "bt": 1, "tt": 4},
...     {"task": "crackle", "bt": 5, "tt": 8},
...     {"task": "pop", "bt": 9, "tt": 12},
...     {"task": "snap", "bt": 3, "tt": 7},
... ]
>>> mermaid_str = mermaid_gantt(
...     annots,
...     title="Example Gantt Diagram",
...     date_format='s',
... )
>>>
>>> print(mermaid_str)
gantt
    dateFormat  s
    axisFormat  %S
    title Example Gantt Diagram
    "snap" : 1, 4
    "crackle" : 5, 8
    "pop" : 9, 12
    "snap" : 3, 7

You can group tasks by a function of the annotation dict. For example, to group by the task name itself:

>>> mermaid_str_2 = mermaid_gantt(
...     annots,
...     title="Example Gantt Diagram",
...     date_format='s',
...     group=lambda x: x['task']
... )
>>> print(mermaid_str_2)
gantt
    dateFormat  s
    axisFormat  %S
    title Example Gantt Diagram
    Section snap
    "snap" : 1, 4
    "snap" : 3, 7
    Section crackle
    "crackle" : 5, 8
    Section pop
    "pop" : 9, 12
